# Ayat Quran v1.2.0

Keep Quran verses close with a home-screen widget, Al-Muyassar tafseer, and passages grouped to preserve meaning.

## What's new

- Home-screen widget with refresh, resize support, the app’s Quran font, and a centered header.
- Al-Muyassar tafseer inside the app and from the notification’s **التفسير** action. Fetched tafseer stays available offline.
- Full-screen reading with tafseer beside each ayah and improved system bar colors.
- Meaningful passages based on QSU semantic boundaries: mostly single ayahs or groups of two to five, preserving longer source groups when needed for meaning.
- Passage-aware bookmarks, sharing, reminders, and reading counts.
- Cairo interface font, a smaller saved-verses search field, and a compact **قرأت · التالي** button.

## Installation

Download **Ayat-Quran-v1.2.0.apk**. Requires Android 8.0 or later.

Signed with the same production key as v1.1.0 and v1.1.1, so it installs as an update to those releases.

QSU boundary data is credited in Settings and distributed under CC BY-NC 3.0. Quran text is unchanged. Reminder delivery remains subject to the phone’s notification and background permissions; force-stopping the app prevents reminders until it is opened again.
