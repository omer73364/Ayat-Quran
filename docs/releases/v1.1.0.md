# Ayat Quran v1.1.0

An updated reading experience with clearer reminder settings and improved reminder recovery.

## What's new

- Redesigned Saved verses, Arabic search, and full-screen reading with adjustable text size.
- Refreshed reminder status, next reminder time, test notifications, and rescheduling feedback.
- Device-aware shortcuts to available auto-start and background-management settings, with guidance for any phone rather than a single brand.
- Improved reminder restoration after restart, clock changes, and app updates.
- Separate daily reminder frequency and reading goals, with safer reading progress and bookmark updates.
- Four fresh screenshots in light mode in the README.

## Installation

Download **Ayat-Quran-v1.1.0.apk**. Requires Android 8.0 or later.

This release starts using a new production signing key. If the previous debug APK is installed, Android requires uninstalling it before installing this release. Uninstalling removes local bookmarks, progress, and settings. Future releases must use this production key to install as updates.

## Reminder setup

Allow notifications and exact alarms, and remove battery/background restrictions. If your phone offers automatic app management, switch it to manual management and allow auto-start and background operation as appropriate. Settings names and availability vary by device; the app cannot read every manufacturer's auto-start switch or enable it on your behalf.

Restart recovery still depends on the phone allowing the app to run in the background. Android force-stop prevents reminder delivery until the app is opened again. Reboot delivery on every manufacturer and OS version has not been verified.
