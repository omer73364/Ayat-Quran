# Ayat Quran v1.1.1

A fresh identity for Ayat Quran, with an open Quran beneath a gold crescent.

## What's new

- New crescent-and-Quran app icon, with adaptive launcher shapes.
- Android 13+ monochrome support for themed icons.
- Matching splash screen and a proper monochrome notification icon.
- Updated website branding and a direct download of this signed APK.

## Installation

Download **Ayat-Quran-v1.1.1.apk**. Requires Android 8.0 or later.

This APK uses the same production signing key as v1.1.0 and installs as an update to that release. Older debug-signed builds must be uninstalled first; uninstalling removes local bookmarks, reading progress, and settings.

Reminder permissions and battery/background settings still depend on the phone. Force-stopping the app prevents reminders until it is opened again.
